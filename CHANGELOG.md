# Changelog

## 0.1.0 — Initial research prototype

- Added deterministic synthetic daily demand for four food SKUs.
- Added weekly-seasonal demand forecast baseline and rolling-origin evaluation.
- Added mixed-integer procurement optimization with supplier capacities, MOQs, lead-time feasibility, storage and optional budget.
- Added reliability risk premium and carbon price terms.
- Added a nominal-price greedy policy comparator and weighted supplier scorecard.
- Added demand-shock, supplier-outage, lead-time-delay and compound scenario re-optimization.
- Added FastAPI endpoints and responsive supply-chain control-tower dashboard.
- Added SCM methodology, mathematical formulation, research protocol, data provenance, limitations and development roadmap.
- Added pytest suite, Python CI matrix and Docker deployment scaffold.
